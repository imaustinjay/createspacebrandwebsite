Admin key

Your new key
  1. Copy it, and keep a copy somewhere safe — this page won't remember it.
  2. Netlify → Site configuration → Environment variables → add ADMIN_TOKEN, paste, save.
  3. Redeploy. Netlify hands variables to functions at deploy time, so a new one doesn't exist until the next build — Deploys → Trigger deploy.
  4. Come back, paste it above, and the stockroom opens.

This is the one value nobody gives you — Stripe's keys come from Stripe, but this one is yours to choose. It is the only thing standing between the internet and the upload endpoint, so let the button pick it rather than thinking of something.

These files are what people buy. Anything uploaded here is served only to someone holding a download token from a paid order — never publicly, never from a guessable URL. Files over the upload ceiling belong behind a link instead.
